## Project Description
This project focuses on front-end accuracy and responsive design. It involves creating a pixel-perfect replica of a login interface to practice styling techniques, form alignment, and user interface consistency. It serves as a practical application of layout management and CSS aesthetics.

## Features
* **Responsive Login Card:** Centered UI that adapts to different screen sizes.
* **Interactive Form Fields:** Styled input fields for Username and Password with icon integration.
* **Password Toggle:** A visual eye-icon to demonstrate UI functionality for hidden text.
* **"Remember Me" Toggle:** A functional checkbox for user preference simulation.
* **Hover Effects:** Dynamic button styling and link transitions for a modern feel.

## Tools Used
* **GitHub:** For version control and team collaboration.
* **HTML5:** To build the semantic structure of the login page.
* **CSS3:** For the blue-gradient background, typography, and card layout.
* **JavaScript:** To handle login button triggers and password visibility.

## Workflow
1. **Repository Setup:** The project leader initialized the repository and set up the main branch.
2. **Branching Strategy:** Each member created an individual branch to work on specific components.
3. **Collaboration:** Code was pushed to GitHub and merged via Pull Requests after peer review.
4. **Bug Fixing:** The team collaborated to resolve layout issues and address browser security warnings.

## Purpose of the Activity
The goal of this activity is to master the **GitHub Flow**—specifically committing, pushing, branching, and merging in a team environment. Additionally, it helps students understand how to build modern web interfaces that are both visually appealing and structurally sound.
